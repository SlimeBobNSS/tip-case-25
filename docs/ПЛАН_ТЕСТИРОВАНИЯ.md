# План тестирования

Требования и сценарии приёмки сверяются с разделом 10 технического задания. Автоматические тесты запускаются через CTest после сборки.

## Автоматические проверки

| Проверяемая часть | Проверка | Связанные критерии ТЗ |
|---|---|---|
| Дата и время | Корректная високосная дата, неверная дата и месяц, форматирование длительности | AT-11 — частично |
| Сессия | Активное состояние, завершение, длительность, запрет нулевого интервала | AT-06, AT-07 — частично |
| Отчёт | Пересечение границ периода, исключение активной сессии, фильтр проекта, неверный период | AT-12, AT-13, AT-15 — частично |
| CSV-хранилище | Создание таблицы, запись и чтение экранированного поля, отказ при неверном заголовке | AT-18 — частично; экспорт AT-17 отдельно не покрыт |
| Контроллер таймера | Запуск по существующей задаче, отказ второго таймера, восстановление активной сессии | AT-03, AT-04, AT-05 — частично |

## Запуск автоматических проверок

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

В Windows с генератором Visual Studio:

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

## Ручная приёмочная проверка

Порядок демонстрации основных пользовательских сценариев приведён в [инструкции преподавателю](ИНСТРУКЦИЯ_ДЛЯ_ПРЕПОДАВАТЕЛЯ.md). Автоматические тесты не заменяют все проверки AT-01–AT-23; приёмку требований, не перечисленных выше, выполняют отдельно по техническому заданию.
